## Objetivo del manual

Construir un manual progresivo donde cada capítulo amplía los conceptos
del anterior, permitiendo que el estudiante comprenda no solo cómo
implementar una tecnología, sino cuándo elegirla y cómo justificar su
uso dentro del diseño de una arquitectura de software moderna.

## Lineamientos editoriales

-   Un archivo Markdown por capítulo.
-   Extensión estimada: 15--20 páginas por capítulo.
-   Diagramas ASCII para explicar conceptos.
-   Ejemplos completos en Python.
-   Casos de uso reales.
-   Comparativas técnicas.
-   Buenas prácticas y errores comunes.
-   Ejercicios y taller al final de cada capítulo.

## Resultado esperado

Al completar todos los capítulos se obtendrá un manual de
aproximadamente 150--200 páginas adecuado para cursos universitarios de
Arquitectura de Software, Computación en la Nube, Desarrollo Backend y
APIs.
