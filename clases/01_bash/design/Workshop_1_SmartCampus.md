# Workshop 1 - Modelando el problema y la primera arquitectura

## Contexto

La Universidad **SmartCampus** desea reemplazar su antiguo sistema de
gestión académica monolítico.

## Objetivos

-   Comprender el problema.
-   Identificar actores y casos de uso.
-   Proponer una arquitectura inicial.
-   Diseñar una API y una base de datos.

## Requerimientos

-   Gestionar estudiantes, docentes, cursos, matrículas.
-   Consultar horarios.
-   Registrar calificaciones.
-   Soportar 500 usuarios simultáneos.
