## Secuencia pedagógica

El primer workshop presenta el balanceamiento con una API Flask muy sencilla. El segundo separa el concepto de reverse proxy del balanceamiento. El tercero integra balanceamiento, múltiples instancias y PostgreSQL compartido. Los talleres cuarto y quinto aíslan la administración de las bases de datos para que el estudiante aprenda primero a construirlas manualmente y después a reproducirlas automáticamente mediante scripts de inicialización.
