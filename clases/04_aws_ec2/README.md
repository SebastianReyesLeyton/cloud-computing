# Workshops — Clase EC2

**Curso:** Computación en la Nube e Internet de las Cosas

Colección de talleres prácticos de Amazon EC2. La secuencia lleva al estudiante desde crear y conectar una instancia hasta desplegar Docker y analizar seguridad, automatización y escalabilidad.

## Secuencia

1. Taller 1 — Crear y conectar una instancia EC2
2. Taller 2 — Administrar una EC2 Linux por SSH
3. Taller 3 — Instalar Docker y desplegar una aplicación
4. Taller 4 — Seguridad de red, Security Groups y endurecimiento básico
5. Taller 5 — Automatización con User Data
6. Taller 6 — EC2 como pieza de una arquitectura escalable

> **Nota:** AWS es un entorno real de nube. Antes de ejecutar los laboratorios, revise las condiciones de su cuenta y elimine los recursos que ya no necesite.
